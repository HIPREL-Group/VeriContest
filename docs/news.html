News

VeriContest is actively maintained. We will keep adding problems and improving existing ones in versioned releases, and we will extend VeriContest beyond Verus to other verification languages, such as Lean and Dafny. Each leaderboard result is tied to the release it was evaluated on, so results stay comparable over time. The changes in each release are listed in the changelog.

  1. October 20, 2026

    VeriContest Leaderboard Released

    The leaderboard is now live, with baseline results for 10 models on all six tasks, for both VeriContest and VeriContest Lite. Submissions are open. Leaderboard · Submit

  2. October 19, 2026

    VeriContest Lite

    A fixed 300-problem subset for smaller evaluations, with the full benchmark’s mix of sources, difficulty levels and proof sizes. About Lite · Hugging Face

  3. October 15, 2026

    Release v2026.10.1

    Revised problem files and the evaluation tools for generating and scoring programs. Release notes

  4. October 8, 2026

    Release v2026.10

    The first versioned release of VeriContest, with 1,006 problems. Release notes
